# Тестовые настройки магазина

Демо-набор можно применить из `/admin` → «Настройки» → «Тестовый пресет» или командой `uv run fragment-bot demo-settings`. По умолчанию набор заполняет поля со значениями по умолчанию. Для намеренной замены настроенных текстов используйте вариант «Заменить значения» с подтверждением или `demo-settings --overwrite`.

| Поле | Тестовое значение |
| --- | --- |
| Название | Fragment Shop · Демо |
| Подзаголовок | Stars, Premium и GRAM |
| Приветствие | Выберите товар в каталоге и пройдите тестовую покупку. |
| Поддержка | Это тестовый магазин. Если возникла ошибка, сообщите администратору теста номер заказа, выбранный товар и статус из раздела «Мои заказы». |
| Условия покупки | Оплата и выдача выполняются в тестовом режиме. Цены и суммы служат для проверки сценария. Укажите публичный Telegram-аккаунт получателя и проверьте его перед оформлением. |
| Конфиденциальность | Тестовый магазин хранит Telegram ID покупателя, username получателя, товар и статус заказа. Эти сведения используются для показа истории и разбора ошибок. |
| Частые вопросы | Как оформить заказ, где посмотреть статус и какие данные нужны для обращения в поддержку. |
| Закрытая витрина | Тестовая витрина на паузе. Загляните позже или откройте раздел поддержки. |
| Иконки | Только премиум. При ограничении Telegram подписи остаются без декоративных иконок. |
| Ссылка на поддержку | Пустая до добавления реального контакта. |

Чтобы получить кнопку «Связаться с поддержкой», укажите ссылку на свой чат поддержки в настройке `support_url`. Её можно редактировать в Telegram или через `uv run fragment-bot set support_url "https://t.me/ИМЯ_ПОДДЕРЖКИ"`, заменив пример на настоящий адрес.

## Что можно менять в Telegram

- **Оформление** — имя, подзаголовок, приветствие, текст кнопки покупки, формат главного экрана, обложка по HTTPS, вид и порядок дополнительных кнопок, стиль иконок и блок последнего заказа.
- **Витрина** — приём заказов, заголовок каталога, порядок категорий и текст закрытой витрины.
- **Оформление заказа** — быстрый выбор себя, покупка для другого аккаунта, срок оплаты от 5 до 120 минут и видимость отправителя во Fragment.
- **Помощь и документы** — заголовок раздела, текст и ссылка поддержки, условия покупки, частые вопросы и конфиденциальность.

Для главного экрана доступны обложка, Rich Message и текст. Стиль «Только премиум» использует пользовательские emoji Telegram. Для ботов, которым Telegram отклоняет их отправку, предусмотрен текстовый вариант. [Bot API](https://core.telegram.org/bots/api#inlinekeyboardbutton)

Консольные команды `settings`, `set КЛЮЧ ЗНАЧЕНИЕ` и `reset-setting КЛЮЧ` читают и меняют ту же базу. Режим, токен бота, Telegram ID администраторов, прокси и данные Fragment и кошелька задаются в локальном `.env`. Их перечень доступен в «Система» → «Параметры запуска».

Демо-магазин поддерживает имитацию счёта и выдачи. Для Stars после одобрения можно скачать тестовый `PreparedTransaction` в карточке заказа.

## Примеры тестовых пакетов

| Товар | Количество → тестовая цена |
| --- | --- |
| Stars | 50 → 100 XTR, 100 → 200 XTR, 250 → 500 XTR, 500 → 1 000 XTR |
| Premium | 3 мес. → 950 XTR, 6 мес. → 1 700 XTR, 12 мес. → 3 000 XTR |
| GRAM для Telegram Ads | 1 → 350 XTR, 5 → 1 500 XTR, 10 → 2 800 XTR |

Пакеты редактируются через «Товары и цены» или командой `uv run fragment-bot product stars 100 200`.
